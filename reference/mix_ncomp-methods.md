# Number of rows or columns of a MixComp object

Function and methods to get the number of component in a mixture object.
For `"MixComp"` objects this is equivalent to `ncol`.

## Usage

``` r
mix_ncomp(x)
```

## Arguments

- x:

  an object, such as `"MixComp"` or `"MixAR"`.

## Value

a number
